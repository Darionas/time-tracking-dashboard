### What I learned

This project helped me deepen my understanding of:
- Using `fetch()` to load JSON data and handling the response with `.then()` and `.catch()`
- Dynamically generating HTML with template literals and `innerHTML`
- Managing state (the current filter) and updating the UI when it changes
- Using `classList` to toggle active states on buttons

### Useful resources

- [How to use promises](https://developer.mozilla.org/en-US/docs/Learn_web_development/Extensions/Async_JS/Promises) - This article on promises by MDN uses fetch heavily in the examples and should provide a good overview of how to handle fetch requests in your projects.
- [Making network requests with JavaScript](https://developer.mozilla.org/en-US/docs/Learn_web_development/Core/Scripting/Network_requests) - This is an in-depth look at network requests and the problem they solve. There's a lot of information here, so start with the first couple of sections.
- [Working with JSON](https://developer.mozilla.org/en-US/docs/Learn_web_development/Core/Scripting/JSON) - This article by MDN explains JSON. It also has an example of fetching data with fetch and populating a webpage with the response.
